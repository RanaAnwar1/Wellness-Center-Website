# 🏋️‍♀️ Wellness Center Website

A responsive website for a modern fitness club, built using **HTML**, **CSS**, and **JavaScript**. It provides a user-friendly experience for exploring services, booking sessions, and learning about the Wellness Center.

## 📄 Pages Overview

### 🏠 Home

* Hero section with CTA button
* Weekly class schedule
* Membership promo

### 👥 About

* Gym mission & history
* Trainer profiles with hover info
* Facility tour with image gallery

### 🛎️ Services

* Overview of gym access, yoga, training & spa
* Booking buttons and visual highlights
* Comparison of service offerings

### 💰 Pricing

* Tiered membership cards
* Price comparison table
* Discount section for students & special offers

### 📞 Contact

* Contact form
* Location & contact details
* FAQ accordion
